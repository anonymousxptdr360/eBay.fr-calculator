# 🇬🇧 eBay.fr Fee & Profit Calculator (Private Sellers)

A lightweight, modern web tool designed specifically for **private sellers (particuliers)** on **eBay France**. This tool helps resellers instantly calculate their net profits or determine the necessary listing price to achieve a specific profit goal.

### 🚀 How to use it

You don't need to install anything. You have two simple options:

**Option 1: Use the Live Website (Recommended)**
👉 **[Click here to use the Calculator](https://stopbordo.odoo.com/calculateur-ebay)**

**Option 2: Use Offline**
Simply download the `index.html` file from this repository and open it in your web browser.
[Download index.html here](index.html)

---

## ✨ Key Features

* **⚡️ Instant Calculation:** No page reloads; calculations happen immediately via JavaScript.
* **📊 Two Calculation Modes:**
    1.  **Profit Calculator:** Input your selling price and shipping cost to see exactly what lands in your pocket.
    2.  **Reverse Price Finder:** Input your *desired* net profit, and the tool calculates the listing price you need to set.
* **🎨 Modern UI:** Built with **Tailwind CSS** for a clean, responsive design that works on mobile and desktop.
* **🇫🇷 Accurate French Fees:** Pre-configured with current eBay.fr fees for private sellers.

## 🧮 Fee Logic Used

* **Variable Fee:** 10.42% (Standard eBay commission + VAT).
* **Fixed Fee:** €0.35 per transaction.

> **Source:** Based on official [eBay.fr fees for private sellers](https://www.ebay.fr/help/selling/fees-credits-invoices/frais-pour-les-vendeurs-particuliers?id=4822).

# 🇫🇷 Calculateur de Frais eBay.fr (Vendeurs Particuliers)

Un outil web léger et moderne conçu spécifiquement pour les **vendeurs particuliers** sur **eBay France**. Cet outil aide les revendeurs à calculer instantanément leurs bénéfices nets ou à déterminer le prix de vente nécessaire pour atteindre un objectif de gain précis.

### 🚀 Comment l'utiliser

Pas besoin d'installation complexe. Vous avez deux options simples :

**Option 1 : Utiliser le site en ligne (Recommandé)**
👉 **[Cliquez ici pour utiliser le calculateur](https://stopbordo.odoo.com/calculateur-ebay)**

**Option 2 : Utiliser hors ligne**
Téléchargez simplement le fichier `index.html` présent dans ce dépôt et ouvrez-le avec votre navigateur internet.
[Télécharger index.html ici](index.html)

---

## ✨ Fonctionnalités Clés

* **⚡️ Calcul Instantané :** Pas de rechargement de page, les calculs se font immédiatement.
* **📊 Deux Modes de Calcul :**
    1.  **Calculer mes gains :** Entrez votre prix de vente et les frais de port pour voir exactement ce qu'il vous reste dans la poche.
    2.  **Définir mon prix (Mode Inversé) :** Entrez la somme *nette* que vous souhaitez gagner, et l'outil calcule le prix auquel vous devez afficher l'objet sur eBay.
* **🎨 Interface Moderne :** Conçu avec **Tailwind CSS** pour un design propre et responsive (compatible mobile et ordinateur).
* **🇫🇷 Frais Français Précis :** Pré-configuré avec les frais actuels d'eBay.fr pour les particuliers.

## 🧮 Logique des Frais

Le calculateur utilise les taux officiels d'eBay.fr pour les vendeurs particuliers :

* **Commission Variable :** 10,42 % (Commission standard + TVA).
* **Frais Fixe :** 0,35 € par transaction.

> **Source :** Basé sur les [frais officiels eBay pour les vendeurs particuliers](https://www.ebay.fr/help/selling/fees-credits-invoices/frais-pour-les-vendeurs-particuliers?id=4822).
